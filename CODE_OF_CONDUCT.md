# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the code and the problem, not the
person. Harassment, insults and personal attacks are not tolerated in issues, pull requests or any other project space.

## Reporting

If someone's behaviour makes you uncomfortable, contact the maintainer privately through
[GitHub private vulnerability reporting](https://github.com/frach/terraform-aws-serverless-pypi-index/security/advisories/new)
(the repository's private channel; start the title with "Code of Conduct"). Reports are handled confidentially. The maintainer may remove comments, lock threads or block
users who break these rules, as described in the Contributor Covenant's enforcement guidelines.
